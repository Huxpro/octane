Use a build-addressed program manifest to replace eligible expanded first-tree host commands with one compact, optionally strided run. A painted Lynx tree verifies program identity, dynamic values, layout, and listener allocation without revisiting or reinstalling every program host; unsupported and mismatched trees retain the complete comparison and repair paths. Large ContextProxy messages are framed and reassembled so the compact run and its acknowledgement cross native payload limits without changing the logical protocol.
