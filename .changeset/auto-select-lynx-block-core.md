Automatically select the static Lynx Block background core for one-shot
production applications only when every authored entry has complete compatible
dual-thread proofs. Keep development, watch, incomplete, and unsupported builds
on the universal core, preserve explicit core overrides, and report the
versioned selection decision in build asset metadata. Complete-range Block
teardown now preserves its accepted dense-run proof as `destroy-run` instead of
expanding one remove/destroy sequence per row on the background wire.
